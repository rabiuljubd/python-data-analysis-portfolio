# SmartPLS PLS-SEM Research Portfolio

## Overview
This repository documents my work in Partial Least Squares Structural Equation Modeling (PLS-SEM) using SmartPLS, supported by Python-based data processing and statistical analysis where applicable.

## Objectives
- Assess measurement model reliability and validity.
- Evaluate structural relationships and research hypotheses.
- Analyze direct and indirect associations.
- Examine effect sizes, explanatory power, and predictive performance.
- Document methodological decisions and research limitations.

## Tools and Technologies
- SmartPLS
- Python
- pandas and NumPy
- SciPy
- Matplotlib
- Jupyter Notebook

## Repository Structure
- `docs/`: Research documentation and methodology.
- `python/`: Data processing and statistical scripts.
- `smartpls/`: Model documentation and exported results.
- `results/tables/`: Statistical tables.
- `results/figures/`: Visualizations and model diagrams.

## Reproducibility
Analysis steps, software versions, variable definitions, and relevant methodological decisions are documented wherever possible. Reproducibility depends on the availability of the required data and software.

## Limitations
Results should be interpreted in the context of the research design, sampling method, measurement specifications, and assumptions of the statistical methods used.

## Data Availability and Ethics
Only data that can be lawfully and ethically shared should be included. Confidential, personally identifiable, or otherwise restricted research data are excluded.
